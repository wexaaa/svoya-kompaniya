# Пакеты вопросов

Скопируйте сюда свои `.siq`: они появятся в библиотеке комнаты после обновления страницы. Другой способ — загрузить пакет через лобби.

В репозитории есть два собственных тестовых пака с встроенными картинками, звуком и видео:

| Пак | Содержание |
| --- | --- |
| [Тест новых функций](<Тест новых функций.siq>) | 28 вопросов: аукционы, варианты кота, вопросы без риска, число и точка, общие ответы, этапы, медиа и финал. |
| [Тест режима Отвечают все](<Тест режима Отвечают все.siq>) | 6 вопросов для проверки одновременных ответов и последовательного перехода. В лобби выберите «Отвечают все · по порядку». |

Порядок проверки и ответы: [Как проверять новые функции](<Как проверять новые функции.md>). В основном паке у «Кота без вопроса» доступно 100–500 баллов с шагом 100.

Для Windows-сборки оба пака с инструкцией можно скачать отдельным архивом из [релиза 1.12.1](https://github.com/wexaaa/svoya-kompaniya/releases/tag/v1.12.1).

Остальные пользовательские `.siq` исключены из Git. Наборы «Хорошая компания» и «Новые механики · пробный набор» встроены в приложение, отдельные архивы им не нужны.
